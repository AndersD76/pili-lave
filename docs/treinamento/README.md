# Material de treinamento — PILI CLEAN

Quatro guias, um pra cada público, todos com espaços marcados pra print de tela:

- **[GUIA_ADMIN.md](GUIA_ADMIN.md)** — painel administrativo: vendas, usuários, cadastro de lavador, gestão de máquinas.
- **[GUIA_LAVADOR.md](GUIA_LAVADOR.md)** — app do lavador: status da máquina, avisos de erro, lavagens e faturamento.
- **[GUIA_CLIENTE.md](GUIA_CLIENTE.md)** — jornada completa do cliente: cadastro, comprar lavagem, chegar na máquina. Inclui a loja de conveniência (em teste).
- **[GUIA_LOJISTA.md](GUIA_LOJISTA.md)** — dono de loja de conveniência: cadastro da loja, produtos e estoque no computador da loja, mensagens e bloqueio de clientes no app. A loja está em construção; o guia é atualizado a cada etapa.

## Como adicionar os prints

Cada guia tem marcações como `![Descrição](imagens/admin/01-login.png)`. Basta:
1. Tirar o print da tela indicada (Win+Shift+S no Windows).
2. Salvar o arquivo **exatamente com o nome** que aparece entre parênteses, dentro da subpasta certa (`imagens/admin/`, `imagens/lavador/`, `imagens/cliente/` ou `imagens/lojista/`).
3. A imagem passa a aparecer sozinha ao abrir o `.md` (no GitHub, VSCode, etc.) — não precisa editar o texto.

As pastas já existem, só faltam as imagens.
